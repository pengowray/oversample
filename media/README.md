# Media for web pages

## hfr-demo.mp4

Turning on HFR, dragging the frequency gutter and the time gutter, then
pressing Play. 19 seconds, 1280 × 720, no sound. `hfr-demo-poster.jpg` is its
last frame.

```html
<video src="hfr-demo.mp4" poster="hfr-demo-poster.jpg" width="1280" height="720"
       autoplay muted loop playsinline></video>
```

Re-record it with `scripts/record-hfr-demo.mjs` (instructions at the top of
the script).

The recording shown is [XC1087684](https://xeno-canto.org/1087684),
Nut-colored Yellow Bat (*Scotophilus nux*), by Wouter Halfwerk, licensed
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). The
clip shows that recording, so a page that uses it credits the recordist and
keeps the licence.
